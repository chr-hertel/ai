Arize Phoenix Feedback Recorder
===============================

Sends feedback of Symfony AI Feedback as annotations on [Arize Phoenix](https://phoenix.arize.com/) traces.

Arize Phoenix Documentation
---------------------------

 * [Capture Feedback](https://arize.com/docs/phoenix/tracing/how-to-tracing/feedback-and-annotations/capture-feedback)
 * [REST API](https://arize.com/docs/phoenix/sdk-api-reference/rest-api/overview)
 * [Create Trace Annotations](https://arize.com/docs/phoenix/sdk-api-reference/rest-api/api-reference/traces/create-trace-annotations)
 * [Authentication](https://arize.com/docs/phoenix/self-hosting/features/authentication)
